### Galton board
<div class="header_line"></div>

This demo provides a visually engaging illustration of the [binomial distribution](https://en.wikipedia.org/wiki/Binomial_distribution) using
a [Galton board](https://en.wikipedia.org/wiki/Galton_board) together with a real-time graph showing how this distribution
gradually approximates the [normal distribution](https://en.wikipedia.org/wiki/Normal_distribution),
thereby illustrating the [central limit theorem](https://en.wikipedia.org/wiki/Central_limit_theorem) <br/>

🐍 A [VPython demo](https://www.glowscript.org/#/user/zeger.hendrikse/folder/Math/program/GaltonBoard) is available as well, see [galton_board.py](https://github.com/zhendrikse/physics-in-python/blob/main/vpython/galton_board.py)<br/>
