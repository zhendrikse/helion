### About
<div class="header_line"></div>

🎯 Illustration of visualizing matrix transformations<br/>
👉 We start with the following transformation in $\mathbb{R}^2$:<br/>

$$
\begin{pmatrix}
x' \\
y'
\end{pmatrix}=
\begin{pmatrix}
a && b \\
c && d
\end{pmatrix}
\begin{pmatrix}
x \\
y
\end{pmatrix},\ \text{with}\ \begin{pmatrix}
a && b \\
c && d
\end{pmatrix}=
\begin{pmatrix}
2 && 1 \\
0 && 1
\end{pmatrix}
$$
