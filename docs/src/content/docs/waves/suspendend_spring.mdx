### About
<div class="header_line"></div>

🎯 A suspended string that eventually comes to rest in a catenary form<br/>
🐍 A [VPython demo](https://www.glowscript.org/#/user/zeger.hendrikse/folder/MyPrograms/program/SuspendedSpring) is available as well, see [suspended_spring.py](https://github.com/zhendrikse/physics-in-python/blob/main/vpython/suspended_spring.py)<br/>
👉 The Catenary (Free-Hanging String):<br/>

$$
y=a\cosh \left(\frac{x}{a}\right)+c
$$
